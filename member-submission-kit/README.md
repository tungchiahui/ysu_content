# 燕鹰战队成员资料填写包

请先阅读 [成员填写说明书](说明书.md)，按身份选择模板。说明书仅提供 Markdown 格式。

学生与指导老师都必须填写 `seasons`。两个模板文件预填 2027、2028 两个赛季，按实际情况修改；填写说明和示例先从 2027 单赛季介绍，多赛季章节按一个、两个、三个赛季逐步演示，详见 [多赛季填写方法](说明书.md#参加多个赛季怎么填)。学生每条记录包含组别和职务，老师每条只填写年份；当前真实成员资料仍只记录 2027。

个人链接仅示例主页、GitHub、GitCode 三项，按需保留。GitCode 的 `https://xxxxxx.xxx/gitcodeID` 是格式占位，提交前换成本人真实的 GitCode 个人主页。

- 学生：[成员资料模板](成员资料模板.md)、[填写示例](填写示例-张三.md)
- 指导老师：[指导老师资料模板](指导老师资料模板.md)、[填写示例](填写示例-指导老师.md)
- 完整字段约束：[成员资料规范](../docs/成员资料规范.md)
