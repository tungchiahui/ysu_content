# 成员资料填写说明

打开 `成员资料模板.md`，把里面的内容改成自己的就行。

改好后，把文件名改成自己的姓名，比如 `张三.md`。

## kind

学生就填 `student`，不用改。

## name（姓名）

填自己的中文姓名，比如 `张三`，要和文件名一样。

## image（头像）

比如你的照片叫 `张三.jpg`，就填：

`/images/member_photo/张三.jpg`

如果照片是 PNG 格式，就把 `.jpg` 改成 `.png`。**照片叫什么名字，这里就写什么名字。**

没有头像的话，可以把 `image` 这一行删掉。

## affiliation（学院）

填自己的学院，比如 `机械工程学院`、`电气工程学院`。

## grade（年级）

填入学年份，比如你是 2026 级，就写 `2026`。

## seasons（参加的赛季）

你参加了哪一年的比赛，就填哪一年。参加过多个赛季，就写多个；没有参加的年份直接删掉。

### year（赛季年份）

比如参加 2027 年的比赛，就写 `2027`。**注意这不是入学年份。**

### group（组别）

填这个赛季自己在哪个组。

可以选：机械组、电控组、硬件组、算法组、运营组。

### roles（职务）

填自己这个赛季的职务。

可以选：队长、副队长、组长、项管、成员。

普通队员填 `成员`。如果既是副队长又是组长，两个都写上。

**举个例子：**

假设你只参加了 2027 赛季，是算法组的副队长兼组长，就这样写：

```yaml
seasons:
  - year: 2027
    group: 算法组
    roles:
      - 副队长
      - 组长
```

如果你参加了两个赛季，比如 2026 年是成员，2027 年是组长，就这样写：

```yaml
seasons:
  - year: 2026
    group: 算法组
    roles:
      - 成员
  - year: 2027
    group: 算法组
    roles:
      - 组长
```

## links（个人链接）

这部分可以不填，没有的链接直接删掉对应那一行。如果一个链接都没有，就把整个 `links` 部分删掉。

- `homepage`：自己的个人网站、博客等。
- `github`：把网址后面的用户名换成自己的 GitHub 用户名。
- `gitcode`：把网址后面的用户名换成自己的 GitCode 用户名。

## 个人介绍

在最下面第二个 `---` 的后面写。想写什么都行，比如个人介绍、做过的项目、比赛经历，搞抽象也可以。

支持 Markdown，也支持普通的 HTML。不想写的话，留空就行。

---

**最后：** 把填好的 `姓名.md` 和头像照片（如果有）一起发给网站维护者就可以了。
