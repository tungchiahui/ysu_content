# RoboMaster 成果来源

核实日期：2026-10-19。成果页数据位于 `data/achievements.json`，由网站 `/research` 读取。

官方公告入口：[RoboMaster 赛事公告](https://www.robomaster.com/zh-CN/resource/announcement/competition)。官网按公告发布获奖名单，并非一份覆盖所有赛季的总表；早期名单也发布于 RoboMaster 官方论坛。

## 收录口径

- 按学校名称“燕山大学 / Yanshan University”、队名、赛季、赛项和奖项等级逐项核对。保留全国赛、区域赛、高校联盟赛、机器人竞技奖及其他专项奖的区别；统计为获奖条目数，不代表全国赛获奖次数。
- 2016、2017 年原始名单中的队名为“机甲猎手”，页面明确保留原名，未据此推断与“燕鹰”的更名或继承关系，也未合并同校“机甲刀锋”的记录。
- 2020 年为线上评审，标题保留此限定；“未达到最低标准”等非获奖条目不收录。个人奖未列入战队成果。
- 官方表格有跨行合并单元格，核对时需同时确认继承的赛区、站点和奖项等级，不能只看学校所在行。
- 2019 年官方总决赛汇总使用图片名单，已对照团体对抗赛总决赛名单中的全国三等奖，以及单项赛“工程攀岛取弹”的全国特等奖。

## 首次参赛及暂缺年份

[燕山大学 2019 年官方报道](https://www.ysu.edu.cn/info/5415/13631.htm)说明自 2015 年首次参赛，故首页概览记录首次参赛年份为 2015。

本次尚未查实 2015、2021 年的获奖记录，暂不填入成果；这不表示当年未参赛或未获奖。其他年份也只列已核实条目，后续可以继续补充。
