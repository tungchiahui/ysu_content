# 新闻资料规范

手写 frontmatter 仅使用 `title` 和 `authors`，与 Wiki 的作者列表写法一致：

```yaml
---
title: 新闻标题
authors: [陈子明]
---
```

- 暂无明确作者时写 `authors: []`，页面不显示空作者行。不把编辑或发布单位推断为个人作者。
- 多人署名写 `authors: [作者甲, 作者乙]`；姓名不能为空或重复。
- 不再填写旧字段 `author`、`date`、`tags`、`image`、`summary`、`bvid`。
- 日期从文件名生成，文件名使用 `YYYY-MM-DD-英文短标题.md`，保存原文发布日期，不使用本次整理日期；历史公告的活动时间在正文写清楚。
- 图片放入 `public/images/news/`，正文使用 Markdown 图片，第一张正文图片自动作为新闻列表封面。不需要单独指定封面字段；无图片的文章沿用纯文字卡片。
- 摘要由正文首段自动生成，首段直接介绍新闻事实。外部新闻整理应附简短原文链接，配图保留来源说明，具体整理记录在 `sources.md`。

网站同步后会运行 `npm run news:check`，校验 frontmatter 字段、文件名日期及本地图片；正常构建保持原有页面风格与布局。
